\# STM32 Weather Station



\## Overview



This project is a two-week embedded systems project built around the \*\*STM32 NUCLEO-F411RE\*\* development board. Goal is to design and implement weather station capable of measuring environmental conditions and displaying them in real time while following embedded software development practices.





\---



\## Hardware



\- STM32 NUCLEO-F411RE

\- Bosch BME280

&#x20; - Temperature

&#x20; - Humidity

&#x20; - Pressure

\- BH1750 Light Sensor

\- SSD1306 128×64 OLED Display

\- Breadboard

\- Jumper wires
